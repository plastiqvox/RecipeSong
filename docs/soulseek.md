# Soulseek 내장 클라이언트

RecipeSong 프로세스 안에서 Soulseek에 직접 로그인하고 검색·다운로드·공유·업로드를 처리한다. slskd 설치, 별도 서버 주소, API 키는 필요하지 않다. 추천 계산과 취향 학습은 바뀌지 않는다.

## 화면 구성

메인 화면 상단의 **추천 / Soulseek** 탭으로 이동한다. 추천 화면의 기간·필터·수록곡 상태를 유지하고, Soulseek 화면에서는 **검색 / 다운로드 / 업로드 / 설정**을 바로 연다. 전송함과 계정 설정은 별도 창으로 띄우지 않는다. 폴더·파일 선택과 가져오기 확인만 대화상자를 사용한다.

탭을 오가도 검색어·검색 결과·선택한 파일·작성 중인 설정을 유지한다. 검색은 **검색 중지**를 누르거나 다른 앨범을 검색할 때 중단한다. 전송은 탭 이동 중에도 계속된다.

## 계정과 공유 설정

**Soulseek → 설정**을 연다. 앱 설정의 **계정·공유 폴더·전송 제한**과 전송함의 **Soulseek 설정**도 같은 탭으로 이동한다.

- Soulseek ID와 비밀번호를 입력하고 로그인한다. 비밀번호 저장은 선택 사항이며 Windows 현재 사용자 계정의 DPAPI로 암호화한다. 자동 로그인은 비밀번호 저장을 켠 경우에만 설정할 수 있다.
- 같은 ID로 SoulseekQt 등 다른 클라이언트에 동시에 로그인하면 기존 연결이 끊길 수 있다. 로그인은 사용자가 직접 실행하며, 자동 로그인을 켠 경우에만 다음 실행 때 연결한다.
- 공유 폴더는 여러 개 추가할 수 있다. 하위 폴더까지 스캔하며 스캔한 파일만 검색·공유 목록·업로드에 제공한다. 폴더 제거는 목록에서만 제거하며 실제 파일을 삭제하지 않는다.
- 정션·심볼릭 링크를 따라가지 않는다. 미완료 파일과 RecipeSong 변환 작업 폴더는 공유에서 제외한다. 업로드를 열기 전에 현재 공유 목록·경로·파일 크기를 다시 확인한다.
- 공유 상태에 스캔한 파일 수와 읽지 못한 항목 수를 표시한다. **저장·다시 스캔**으로 디스크 변경 사항을 반영한다. 파일 시스템을 계속 감시하는 기능은 없다.

수신 포트의 기본값은 50001이다. 고급 설정에서 변경한 포트는 로그아웃 후 다시 로그인하면 적용된다. 외부에서 공유 목록이나 전송에 연결하지 못하면 Windows 방화벽과 라우터의 포트 설정을 확인한다. 방화벽·라우터 설정은 앱이 자동으로 변경하지 않는다.

## 설치된 Soulseek NS 설정 가져오기

Soulseek 설정의 **설치된 Soulseek 설정 가져오기…**를 누른다. Windows 현재 사용자 레지스트리의 `Software/Soulseek2/config`를 읽어 NS 157의 ID·비밀번호·다운로드 폴더·공유 폴더를 가져온다. 32비트·64비트 레지스트리 보기를 확인하며 원본 키는 수정하지 않는다.

미리보기에서 가져올 항목을 선택한다. 비밀번호는 고정된 가림 문자로만 표시하고 가져오면 **비밀번호 저장**을 켜 Windows 계정으로 암호화한다. 자동 로그인은 끈 상태로 둔다. **선택한 설정 가져오기**는 설정 칸에 값을 채우며 **설정 저장**을 눌러 보관한다.

원래 다운로드 폴더는 **원본 다운로드 폴더**에 들어간다. ZIP 저장 폴더는 기존 값을 유지한다. 공유 폴더는 기존 목록에 중복 없이 추가하며 실제 파일을 이동하거나 삭제하지 않는다. 두 NS 공유 목록이나 공유 권한에 확인이 필요한 경우에는 폴더를 자동 선택하지 않고 사용자가 공개할 폴더를 직접 고르게 한다.

NS 레지스트리 바이너리의 길이 지정 문자열·공유 목록 구조와 Windows ANSI 코드 페이지를 처리한다. 실제 SoulSeek 157 NS 13e 설정으로 ID·비밀번호·다운로드 폴더·공유 폴더 인식과 암호화 저장·복원을 확인했다. 계정·비밀번호의 실제 값은 검사 출력에 포함하지 않았다.

## SoulseekQt 설정 가져오기 범위

**SoulseekQt 폴더 후보 가져오기…**에서 `soulseek-client.dat*` 파일을 선택한다. `%LOCALAPPDATA%/SoulseekQt` 아래에 파일이 있으면 가장 최근 파일의 위치를 제안한다. 원본 설정 파일은 읽기만 한다.

현재 구현은 Qt의 길이 지정 UTF-16 문자열과 qCompress 압축 데이터를 읽어 이 PC에 존재하는 로컬 폴더 후보를 찾는다. 실제 공유 폴더라는 의미까지 확인할 수는 없으므로 모두 선택 해제한 미리보기에서 사용자가 공유할 폴더만 고른다. 네트워크 경로는 설정 파일을 읽는 것만으로 접속하지 않도록 자동 검사에서 제외한다.

**ID·비밀번호·슬롯·속도 제한의 자동 가져오기는 지원하지 않는다.** SoulseekQt의 전용 바이너리 형식과 실제 사용자 설정 표본을 확인하지 못했으므로 값을 추측해 적용하지 않는다. 읽을 수 없는 버전이면 폴더도 직접 추가해야 한다. 현재 확인한 것은 합성한 Qt 문자열 표본이며 실제 SoulseekQt 설정 파일 호환성은 미검증이다.

## 전송 제한

다운로드와 업로드를 따로 설정한다.

| 항목 | 의미 |
|---|---|
| 동시 전송 슬롯 | 전체 동시 파일 수, 1~100 |
| 사용자당 슬롯 | 한 사용자와 동시에 전송할 파일 수, 1~100 |
| 전체 속도 제한 | 방향별 합산 속도, KiB/s |
| 무제한 | 속도 제한을 사용하지 않음 |

속도 변경은 진행 중 전송에도 적용한다. 슬롯을 줄일 때는 이미 진행 중인 파일을 끊지 않고 다음 파일부터 새 한도를 적용한다. 한 사용자가 자기 슬롯을 다 쓰고 있으면 다른 사용자가 빈 슬롯을 쓸 수 있다. 상대가 업로드 슬롯을 제공하지 않거나 오프라인이면 대기·실패할 수 있다.

## 앨범 검색과 다운로드

추천 앨범의 수록곡 창이나 카드 메뉴에서 **Soulseek 검색·다운로드**를 누르면 **Soulseek → 검색**으로 이동한다. 아티스트·앨범 이름이 검색어로 채워지고 직접 수정할 수 있다. 로그인 전 검색을 누르면 **설정** 탭으로 이동하고, 로그인 성공 후 검색으로 돌아와 요청한 검색을 시작한다. **추천으로**를 누르면 추천 탭으로 돌아간다.

결과는 사용자·앨범 폴더 단위다. 포맷·음질·곡 수·용량·사용자·슬롯·대기열·상대 속도를 보고 **수록곡 확인·선택**을 펼쳐 받을 곡을 고른 뒤 **선택한 곡 다운로드**를 누른다. 대기열이 적은 순(0개 우선), 같은 대기열에서는 상대 속도가 빠른 순으로 정렬한다. 둘 다 같으면 사용자·폴더 이름 순이다. 검색 중 새 결과가 들어오거나 확장자 필터를 바꿔도 같은 정렬을 적용한다. 잠긴 파일과 음원이 아닌 파일은 결과에 포함하지 않는다.

**상대 속도**는 검색 응답의 업로드 속도를 KiB/s 또는 MiB/s로 표시한 참고값이다. 실제 내 다운로드 속도를 보장하지 않으며 실제 수신 속도는 다운로드 탭에서 확인한다. 0 이하의 값은 **정보 없음**으로 표시하며 같은 대기열의 알려진 속도 뒤에 둔다.

결과마다 **다운로드 가능**(초록색) 또는 **다운로드 대기** 배지, **상대 빈 슬롯: 1개 이상 / 없음**, **대기열 N개**를 함께 표시한다. 상대가 빈 슬롯을 보고하면 대기열이 남아 있어도 다운로드 가능으로 표시한다. 검색 응답은 빈 슬롯 유무만 제공하므로 정확한 빈 슬롯 수를 추정하지 않는다. 대기열은 검색 응답 당시 상대방의 전체 업로드 대기 수이며 내 대기 순번이 아니다. 실제 요청 시 슬롯과 대기 수는 달라질 수 있다.

로그인 중에는 Soulseek 화면 상단에 **내 빈 다운로드 슬롯: N/M개**를 1초 간격으로 갱신한다. 모든 앨범이 공유하는 전체 슬롯 기준이며, 사용자당 슬롯 제한과 상대방 상태에 따라 실제 전송이 대기할 수 있다. 상대 빈 슬롯과 내 빈 슬롯을 구분해서 본다.

검색 화면의 **파일 확장자**에서 전체·MP3·FLAC·OGG·OPUS·M4A·AAC·WAV·AIFF·AIF·WMA·ALAC 중 하나를 고른다. 재검색 없이 받은 결과를 걸러 내며 검색 중 새로 들어오는 결과에도 같은 필터를 적용한다. 혼합 폴더는 해당 확장자의 파일만 표시하고 다운로드 대상으로 삼는다. 곡 수·용량도 필터 기준이다. 표시/전체 폴더 수를 보여 주고, 일치하는 결과가 없으면 필터 변경을 안내한다. 전체로 돌아가면 숨겨진 파일과 원래 체크 상태를 복원한다. 같은 앨범의 검색 화면에서 탭을 오갈 때 필터도 유지된다.

폴더 전체를 내려받는 요청은 보내지 않는다. 선택한 곡마다 별도 파일 다운로드 요청·대기·전송 상태를 만든다. 한 곡이 실패해도 나머지 곡 요청을 취소하지 않는다. 모든 파일 요청이 끝난 뒤 실패가 있으면 앨범 실패 사유를 표시하고, 다시 시도하면 완료 파일은 재사용하며 실패한 곡은 이어받는다. ZIP은 선택한 곡 전부가 완료된 경우에만 만든다. 동시 전송은 전체·사용자당 슬롯 제한을 따른다.

검색 전에 Deezer 앨범 상세의 전체 곡수(`nb_tracks`)를 확인한다. 확장자 필터 적용 후 음원 수가 앨범 곡수와 같은 폴더만 표시하며 부족한 목록·보너스 곡이 더 있는 목록은 숨긴다. 전체 곡수를 확인하지 못하면 결과를 표시하지 않고 재검색을 안내한다. 곡수 일치는 곡명·판본 일치를 보장하지 않으므로 수록곡을 확인한다. 멀티디스크가 별도 폴더로 나뉜 결과도 폴더별 곡수가 전체 곡수와 다르면 숨긴다.

선택한 곡만 받으므로 앨범 전곡과 원하는 판본이 맞는지 확인한다. 서로 다른 사용자의 파일을 자동으로 합치거나 판본을 자동 판별하지 않는다. 검색 중지 후에도 이미 받은 결과는 남는다. **추천으로**를 누르면 추천 탭으로 돌아온다.

## 전송함

**Soulseek → 다운로드 / 업로드**에서 전송 상태를 확인한다. 메인 화면의 **전송함** 버튼도 다운로드 탭으로 이동한다. 진행 중 앨범 수는 버튼에 표시하고 앨범 카드에는 받는 중·ZIP 완료·실패 상태를 붙인다.

다운로드 화면은 왼쪽 **앨범 목록**, 오른쪽 **다운로드 상태**로 나눈다. 왼쪽에서 앨범을 선택하면 오른쪽에 해당 앨범의 곡 전체를 표시한다. 전송 요청 전·이전 실행에서 받은 곡·ZIP 저장 완료한 곡도 포함한다. 재시도 기록은 최신 시도로 모으며 1초 갱신 중에도 선택한 앨범을 유지한다. 가운데 구분선으로 폭을 조절하고 각 목록을 별도로 스크롤한다.

앨범 목록 아래에는 **다시 시도 / 다른 상대 찾기 / 더보기**만 배치한다. 다시 시도는 실패·중단 상태에만 표시한다. 즐겨찾기·폴더 열기·앨범아트 교체·파일 정리·중단·기록 삭제는 더보기 메뉴로 옮기고 해당 앨범 상태에 맞는 항목만 표시한다. 오른쪽의 중복 중단 버튼과 전송 화면의 설정 버튼은 제거하고 계정 설정은 상단 설정 탭을 사용한다.

**다른 상대 찾기**는 이전 상대를 제외하고 같은 앨범을 다시 검색한다. 새 상대를 선택하기 전까지 기존 작업은 유지하고, 새 판본을 받기로 하면 기존 전송 종료·파일 정리를 기다린 뒤 별도 작업으로 받는다. 상대별 파일은 섞지 않는다.

**즐겨찾기 등록 / 즐겨찾기 해제**는 기존 저장함과 연동한다. 새 작업에는 추천 앨범 정보를 함께 기록한다. 예전 기록에 ID가 없으면 현재 추천·저장함에서 찾거나 Deezer에서 아티스트와 제목이 일치하는 앨범만 연결한다.

- 다운로드 탭: 앨범별 음원 진행률·완료 곡 수·받은 용량·속도·예상 남은 시간과 처리 단계를 1초 간격으로 갱신한다. 파일별 진행률·상태·오류를 표시하고 **다운로드 상세 정보**에서 상대 사용자·저장 경로·접속 주소·시간을 확인한다. 취소·재시도·앨범아트 교체·완료 폴더 열기도 제공한다. 진행률은 음원 다운로드 기준이며, 100% 이후 MP3 변환·앨범아트·ZIP 처리 단계와 ZIP 저장 완료를 구분한다. 이전 실행에서 받은 원본·미완료 파일 용량도 합산한다.

- 업로드 탭: 공유 파일 수와 대기·전송·종료 건수, 상대 사용자·파일별 전송량·속도·진행률을 표시한다. 상세 정보에는 공유 경로·내 파일 경로·상대 접속 주소·요청/시작/종료 시각·경과 시간·대기 순서·예상 남은 시간을 표시한다. 선택 업로드를 취소할 수 있으며 재요청은 상대 사용자가 한다.
- 상단: 방향별 사용 슬롯과 합산 전송 속도·제한.

검색 결과에서 **선택한 곡 다운로드**로 작업을 추가하면 다운로드 탭으로 이동한다. 검색 화면의 **다운로드 상태 보기**로도 언제든 이동할 수 있으며 검색 결과는 유지한다.

여러 앨범의 다운로드를 동시에 진행한다. 한 앨범이 상대방 대기열에 있거나 MP3·ZIP 처리 중이어도 다른 앨범의 다운로드를 시작한다. 다운로드 슬롯·사용자당 슬롯·속도 제한은 모든 앨범이 공유하며 앨범 수만큼 늘어나지 않는다. MP3 변환·앨범아트·ZIP 생성은 CPU 사용과 파일명 충돌을 줄이기 위해 한 앨범씩 처리한다. 앱 종료 시 모든 실행 중 앨범의 중단·기록 저장을 기다린다.

상대방에게 대기 중인 파일에는 **상대 대기열 N번째 · 앞에 M개**와 최근 확인 시각을 표시한다. 대기 중인 전송에 대해 약 15초 간격(응답 대기 최대 5초)으로 실제 순번을 조회하며 동시 조회는 2개로 제한한다. 1번째면 앞에 0개로 표시한다. 응답이 없거나 0 이하의 값이면 즉시 전송 가능으로 해석하지 않고 순번 미제공으로 표시한다. 앱의 다운로드 슬롯을 기다리는 경우는 **내 다운로드 슬롯 대기**로 구분한다. 상대 순번으로 대기 시간을 추정하지 않는다.

한 번 전송을 시작한 곡이 완료되지 않은 채 대기로 돌아오면 **다운로드 후 다시 대기 중**으로 표시하고 재대기 시작 시각·경과 시간을 보여 준다. 받은 용량과 진행률을 유지하며 상대 대기열·내 슬롯 대기는 기존 순번 정보와 함께 구분한다. 앨범에는 재대기 곡 수를 표시하고, 활성 전송이 없이 재대기 곡만 있으면 **다운로드 재대기 중…**으로 표시한다. 전송 재개 시 재대기 표시를 지운다. 사유를 별도로 받지 못한 경우 네트워크 단절 등으로 추측하지 않는다.

탭 이동 중에는 전송을 계속한다. 앱 종료 시에는 원본·미완료 파일을 보관한다. 전곡을 받은 작업은 재실행 후 Soulseek 로그인 없이 변환·ZIP 저장을 이어가며, 받을 곡이 남은 작업은 해당 계정 로그인 후 재개한다. **중단·파일 삭제**는 해당 앨범의 전송 종료를 기다린 뒤 받은 원본·`.partial`·변환 임시 파일을 삭제한다. 중단은 앨범 목록의 **더보기 → 중단·파일 삭제** 한 곳에서 수행한다. 오류로 실패한 파일은 재시도할 수 있게 보관하며 직접 중단하면 정리한다. 취소한 작업을 **다시 시도**하면 삭제된 곡을 새로 받는다. 작업 폴더 안의 알 수 없는 파일·다른 작업·완료 ZIP은 삭제하지 않는다. 심볼릭 링크·정션이 있는 경로는 자동 정리를 거부하고 정리 실패 사유를 앨범에 표시한다.

파일 전송 내역은 현재 실행 동안만 보관하고 앨범 작업은 캐시의 `soulseek-native-downloads.json`에 저장한다. 기존 slskd 방식의 `soulseek-downloads.json`은 보존하며 자동 재개하지 않는다.

완료 ZIP과 원본 경로·곡 목록·작업 ID, 정리 대기 여부·최근 시도 시각·완료 시각을 기록에 저장한다. ZIP 저장 성공 후 정리하고, 정리 실패·중간 종료 시 앱 시작 때와 30초 간격으로 재시도한다. **더보기 → 파일 정리 재시도**로 선택한 완료·중단 앨범을 수동 정리할 수도 있다. 완료 ZIP이 없거나 손상됐거나 저장 드라이브가 연결되지 않았으면 원본을 보관하고 정리를 대기시킨다. 정리할 파일이 남은 기록은 먼저 정리해야 삭제할 수 있다. 추적 범위는 현재 다운로드 기록에 남아 있는 작업이다.

**선택 기록 삭제**는 선택한 종료 앨범의 기록을 지운다. **종료 기록 모두 삭제**는 완료·실패·취소된 앨범 기록을 한꺼번에 지운다. 해당 앨범의 종료된 파일 전송 기록도 화면에서 제거한다. 진행 중·대기 중인 작업, 파일이 남아 있는 작업과 업로드 기록은 유지한다. 기록 삭제 자체는 음원·ZIP·미완료 파일을 삭제하지 않는다. 기록 저장에 실패하면 화면의 기록도 유지한다.

## MP3·앨범아트·ZIP

선택한 파일이 모두 성공하고 크기가 맞는지 확인한 후 처리한다.

- MP3 오디오는 재인코딩하지 않는다. FLAC·OGG·Opus·M4A·AAC·WAV·AIFF·WMA·ALAC 등은 MP3 320kbps로 변환한다.
- 추천 앨범아트를 기본으로 사용한다. 그림이 없는 앨범은 파일 선택을 요청한다. 아트 수신에 실패하거나 그림을 바꾸려면 전송함의 **앨범아트 바꿔 재처리**를 사용한다.
- ZIP에 `cover.jpg`를 넣고 모든 MP3에 같은 그림을 내장한다. 아티스트·앨범·발매일 태그를 넣으며 기존 곡 메타데이터를 가져온다.
- 출력 MP3에는 앨범명·아티스트·앨범 아티스트·발매일·앨범아트를 기록하고, 파일명에 사용한 곡명·트랙 번호·디스크 번호도 같은 정보로 갱신한다. 원본 태그의 유효한 전체 트랙 수·전체 디스크 수는 보존한다. 일부 곡만 선택했다고 선택 곡 수를 전체 곡 수로 기록하지 않으며 전체 수를 알 수 없으면 비워 둔다. 곡명 태그의 문장부호는 보존하고 파일명에만 금지 문자를 바꾼다.
- ZIP 안 음원 이름은 일반 앨범 `01_곡명.mp3`, 멀티디스크 앨범 `1-01_곡명.mp3` 형식이다. 트랙 번호는 최소 두 자리이며 디스크 번호는 여러 디스크가 확인될 때만 붙인다. 음원 태그의 디스크 번호·전체 디스크 수·트랙 번호·제목을 우선하고, 빠진 정보는 원래 공유 파일명과 CD/Disc/Disk 폴더명에서 보완한다. 트랙 번호까지 없으면 선택 목록 순번을 쓴다. 파일명 금지 문자는 `_`로 바꾸고 중복은 ` (2)` 등을 붙여 보존한다. 이어받기용 원본·임시 경로는 유지하며 새로 만드는 ZIP부터 적용한다.
- 곡 하나나 앨범아트 처리라도 실패하면 완성 ZIP을 만들지 않는다. 원본 음원은 보존한다.
- `[yyyy.MM.dd] (Album|EP|Single) 뮤지션 - 앨범제목.zip`으로 설정한 ZIP 폴더에 저장한다. Windows 파일명에 쓸 수 없는 문자는 `_`로 바꾼다. 새로 만드는 ZIP부터 적용하며 기존 ZIP의 이름은 변경하지 않는다.
- 기존 ZIP은 덮어쓰지 않고 ` (2)`부터 번호를 붙인다. 앱은 ZIP 저장 성공 후 원본·미완료 파일과 변환 임시 파일을 정리한다. 실패한 파일은 재시도용으로 보관하고 직접 중단한 작업은 정리한다.

예: `[2026.02.03] (Album) Cory Wong - Lost In The Wonder.zip`

FFmpeg는 `tools/ffmpeg/ffmpeg.exe`에서 빌드·배포물에 복사된다. 사용자에게 별도 설치나 PATH 설정은 필요하지 않다. 소스 체크아웃에서 빌드할 때는 해당 실행 파일을 준비한다. 고급 설정의 변환기 경로는 별도 빌드를 쓸 경우에만 지정한다. 실행 파일 출처·해시·라이선스는 `tools/ffmpeg/README.txt`, 통신 라이브러리 고지는 `tools/soulseek/README.txt`와 각 LICENSE에 있다.

## 검증과 남은 확인

```powershell
dotnet build tests/Soulseek.Checks/Soulseek.Checks.csproj -o <검증 출력 폴더>
dotnet <검증 출력 폴더>/Soulseek.Checks.dll C:/tools/ffmpeg/bin/ffmpeg.exe
dotnet <검증 출력 폴더>/Soulseek.Checks.dll --album-actions C:/tools/ffmpeg/bin/ffmpeg.exe
dotnet <검증 출력 폴더>/Soulseek.Checks.dll --transfer-states
dotnet <검증 출력 폴더>/Soulseek.Checks.dll --track-names C:/tools/ffmpeg/bin/ffmpeg.exe
dotnet build tests/Soulseek.UiChecks/Soulseek.UiChecks.csproj -o <화면 검증 출력 폴더>
dotnet <화면 검증 출력 폴더>/Soulseek.UiChecks.dll <이미지 출력 폴더>
```

가짜 계정으로 NS ID·비밀번호·폴더 파싱·한글 인코딩·손상된 데이터 거부·비밀번호 출력 방지, 비밀번호 암호화·저장 해제, 슬롯·사용자당 제한·취소·실행 중 한도 변경, 공유 제거·경로 접근 제한·검색 제외어, 합성 Qt 폴더 후보, 실제 FLAC·OGG·MP3 변환·내장 앨범아트·ZIP을 검사한다. `--album-actions`는 ZIP 성공 후 원본 정리, 실패 시 보관, 진행 중 작업의 직접 중단 후 정리, 앱 종료 시 이어받기용 보관, 재실행 후 로그인 없는 변환·정리 재시도, 잠긴 파일·없거나 손상된 ZIP의 원본 보호, 다른 파일·완료 ZIP 보호와 앨범 정보·즐겨찾기 저장을 별도 데이터로 확인한다. 링크 생성 권한이 없는 환경에서는 링크 경로 검사만 생략한다.

화면 검증은 앱 시작·로그인·소리 서비스를 실행하지 않고 한국어·영어 화면을 렌더한다. 탭 왕복 상태 유지, 앨범 선택에 따른 곡별 목록·선택 유지, 즐겨찾기 등록·해제, 다른 상대 재검색과 로그인 이동을 검사한다. 실제 사용자 앱은 조작하지 않는다.

실제 Soulseek 로그인·다른 사용자와의 검색·공유 탐색·전송·속도 제한은 아직 확인하지 못했다. Soulseek.NET 10.0.2는 NuGet에서 `CriticalBugs` 사유로 deprecated 표시되어 있으며 구체적인 설명과 대체 패키지는 제공되지 않는다. 실서버 호환성과 배포 라이선스 확인을 마치기 전에는 배포 검증 완료로 보지 않는다. 사용자 버전 식별자는 라이브러리 기본 major 170과 RecipeSong용 minor 8100001을 사용한다.
